# صفحة هبوط «تطبيقات المنهج السوداني الذكية» — بهوية Experience Media

**الرابط المنشور:** https://aljompolaty.github.io/sudan-curriculum/

ملف واحد مستقل: `index.html` — يعمل بالنقر المزدوج بدون إنترنت وبدون أي ملفات إضافية
(الخطوط والشعار والصور كلها مضمّنة داخل الملف).

## ما طُبِّق من الهوية
- خط **Thmanyah Sans** (400/500/700/900) + **Thmanyah Serif Display** للاقتباس، مضمّنة WOFF2/base64.
- ألوان الهوية فقط: أزرق `#00ADEF` للإجراءات، فحمي/محايد للهيكل، ونص أزرق غامق `#0077A6` على الخلفيات الفاتحة.
- نص الأزرار فوق الأزرق `#151618` دائمًا (لا أبيض).
- RTL أولًا، تباعد حروف = 0، وزيادة line-height.
- زوايا 4px افتراضيًا (8px للبطاقات الكبيرة)، والـ pill للشارات فقط.
- الشعار الرسمي: نسخة reverse على الداكن وcolor على الفاتح، دون تمديد أو تلوين أو ظلال، وبمساحة آمنة.
- نمط الشيفرون الرسمي كخلفية خفيفة في الـ hero فقط (خارج النصوص الطويلة).
- وضعان كاملان: داكن/فاتح عبر semantic tokens مع زر تبديل، ويتبع تفضيل النظام أول مرة.
- أيقونات SVG بخط 2px بدل الإيموجي في واجهة الصفحة، مع حالات focus/hover/disabled.

## التغييرات الوظيفية
- أُزيل زر «تحميل الصفحة» من رأس الصفحة بناءً على طلبك.
- بقي كل شيء آخر يعمل: النسخ، الفلاتر، تبويبات المقارنة، الاختبار التفاعلي، النموذج وواتساب، الصوت، والوضعان.

## النشر على GitHub Pages
1. أنشئ مستودعًا باسم `sudan-curriculum`.
2. ارفع `index.html` في الجذر.
3. Settings → Pages → Branch: main → Save.
4. الرابط: `https://aljompolaty.github.io/sudan-curriculum/`
